How to Publish on GitHub Pages

You can host this entire question bank on GitHub Pages completely free in less than 2 minutes! Follow these quick steps:

1
Download your standalone app file Click the "Download GitHub index.html" button from the top header menu. This creates a standalone copy with your custom questions embedded!
2
Create a free GitHub Repository Go to github.com/new. Name your repository (e.g. my-questions), set it to Public, and click Create repository.
3
Upload `index.html` On your repository page, click uploading an existing file. Drag and drop your downloaded index.html file, then click Commit changes.
4
Enable GitHub Pages In your GitHub repo, navigate to Settings → Pages (on the left menu). Under Build and deployment, set Source to Deploy from a branch and select main / root. Save changes!
Your Live Website URL will be:

https://<your-username>.github.io/<repo-name>/
